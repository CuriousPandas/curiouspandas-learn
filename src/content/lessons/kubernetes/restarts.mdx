**CrashLoopBackOff** is the most famous status in Kubernetes, and it tells you almost nothing. It means the container keeps exiting and the kubelet keeps restarting it, waiting longer each time. The docs give the curve: 10s, 20s, 40s and so on, capped at 5 minutes, resetting once a container has run for 10 minutes without trouble.

So *something* is wrong. The status won't say what.

## The number that isn't an answer

The usual next step is the exit code. Here's the trap: both pods in this lesson exit with **137**. That's 128 + 9, and signal 9 is SIGKILL. It tells you something killed the process. It doesn't tell you who did it or why.

This isn't made up. The tilt platform hit both for real. Keycloak was **OOMKilled at a 2Gi limit, eight restarts deep**. Wazuh's API was killed by its own liveness probe before it finished starting, and the error that surfaced pointed at a different component entirely.

## The two fields that actually tell you

1. **The termination reason** (`Last State: Terminated, Reason: ...` in `kubectl describe pod`). `OOMKilled` means the kernel killed it for using more memory than its limit.
2. **The events.** `Liveness probe failed` followed by `Killing` means the kubelet killed it because a health check gave up.

<KubeSim mission="kube-two-crashes" title="starved and impatient" />

<Callout kind="trap">
"Give it more memory" is the reflex, and for **impatient** it changes nothing. That process is healthy, just slow. Its liveness probe starts checking after 15 seconds and kills it before it finishes starting. Raising memory leaves it crash-looping forever. Try it.
</Callout>

## Why a startup probe, not a longer delay

The right fix for a slow start is a **startupProbe**. The Kubernetes docs say that while a startup probe is configured, liveness and readiness checks don't run until it succeeds. Startup gets as long as it needs, and then liveness takes over with its normal tight interval.

The tempting alternative is a big `initialDelaySeconds` on the liveness probe. It works on day one, but then a real hang takes minutes longer to notice, forever.
